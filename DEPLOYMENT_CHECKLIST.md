# Submission checklist

- [ ] Run the backend and verify `http://127.0.0.1:8000/health`
- [ ] Run the frontend and test all six modules
- [ ] (Optional) Add a Gemini API key to backend environment variables for real model responses
- [ ] Create a public GitHub repository and upload the project files
- [ ] Deploy the FastAPI backend and configure `GEMINI_API_KEY` as a server-side secret
- [ ] Deploy the frontend and set `VITE_API_BASE_URL` to the deployed backend URL
- [ ] Test the deployed frontend and backend from a fresh browser
- [ ] Enter the real GitHub repository URL in Skill Wallet's Add Github Link field
- [ ] Enter the real deployed app URL in Skill Wallet's Add Demo Link field

Do not submit example or placeholder URLs. The source project package does not itself create a GitHub repository or a hosted public demo.
